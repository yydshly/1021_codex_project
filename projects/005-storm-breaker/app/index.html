IP 与访问记录无需弹窗服务器看到请求来源 IP、时间和请求内容。代理 / VPN 通常呈现出口 IP；推测城市与运营商不等于知道门牌、姓名或 GPS 坐标。

屏幕与粗略硬件能力无需弹窗窗口 / 屏幕尺寸、像素比例、触摸能力、逻辑处理器数量；部分浏览器提供粗略内存。不是完整 CPU、内存或显卡清单。
当前页面内的行为与输入无需弹窗页面内点击、滚动、鼠标移动、停留、可见状态、表单文字。尚未提交的文字和本站密码框也可能被读取；圆点只是视觉遮挡。不能据此监听其他应用键盘输入。
本站存储与登录关联无需弹窗脚本可读取本站可访问的 Cookie、localStorage、IndexedDB；服务器可关联本站账号。HttpOnly Cookie 对脚本不可读，仍可由浏览器随适用请求发送。
浏览器指纹通常无需弹窗Canvas、WebGL、音频计算等特征可用于概率性关联访问；可能被限制或加噪。音频指纹不等于监听麦克风，指纹也不是绝对唯一、永久稳定的设备身份证。
摄像头画面摄像头权限获取获准摄像头的实时画面，可拍照、录像、上传；不包含相册。已有有效授权可能不再次弹窗，使用时仍有浏览器 / 系统指示。
麦克风声音麦克风权限获取麦克风媒体流；不自动获得系统内部声音或通话记录。房间中实际播放并被麦克风拾取的声音属于间接采集。
地理位置位置权限经纬度与精度，视环境可能有海拔、速度等。一般网页可请求持续更新；本仓库仅单次定位。高精度请求不保证 GPS 来源或米级结果。
屏幕 / 标签页 / 窗口选择共享范围获取用户所选画面；部分环境支持音频。每次启动屏幕共享都需授权。共享整个屏幕时，显示出来的其他应用信息也可能被录下。
文件、照片与目录选择文件 / 目录读取用户选择的文件内容和元数据；目录授权可能涵盖内部文件。原始照片可能含 EXIF 时间和位置；不能因此扫描未授权磁盘。写入权限可能另行申请。
剪贴板授权或主动粘贴读取浏览器支持的当前剪贴板内容，受焦点、用户操作及权限规则约束；不同浏览器不同。不是读取完整剪贴板历史。
联系人联系人选择器在支持的浏览器中，获取用户选定联系人及字段。不是静默读取全部通讯录，也不是所有平台通用。
USB、蓝牙、串口等外设特定设备授权在支持的平台和接口下访问获准设备暴露的数据。设备协议与受保护类别仍限制访问；不等于获得所有硬件或系统管理权限。
其他网站的私有数据不能任意读取其他网站 Cookie、页面内容、登录令牌受同源策略等保护。对方主动提供接口、明确授权的数据共享或存在漏洞属于不同情况。
浏览器全部保存密码无通用读取接口网页不能导出密码库；用户输入或填入当前网站表单的密码则可能被该页面读取。WebAuthn / 通行密钥也不把私钥直接交给网页。
全部历史、书签、标签页清单无全量读取接口普通网页不能枚举浏览器全部记录。当前页面的 URL、受策略限制的来源信息、本站访问日志不等于完整浏览历史；扩展属于另一种权限体系。
未选择的硬盘文件与相册不能任意扫描需要对应文件 / 目录的访问权；已选文件和授权目录属于上一类。网站自己创建的浏览器沙箱存储也不等于用户硬盘任意路径。
聊天、短信与通话记录库无通用读取接口不能直接读取其他应用数据库。主动上传导出文件、共享聊天画面或特定受限验证码 API 不等于获得整个数据库。
进程内存、全局按键、系统命令浏览器沙箱之外常规网页授权不会授予读取其他进程内存、全局键盘记录或任意系统命令执行能力。安装软件、扩展特权和漏洞不属于普通网页权限。
本机 MAC、IMEI、SIM 身份无通用读取接口普通网页不能直接查询这些本机硬件身份标识。媒体设备 ID 或浏览器指纹不等于真实 MAC、IMEI 或电话号码。

05 / LIFECYCLE

关掉网页，
权限和采集会一起消失吗？

权限是否保留，与代码是否运行，
是两个独立的问题。

解释模型 · 不是真实权限检测

选择一个访问情境

包括临时授权仍处于有效期，或浏览器保存了授权。关闭情境假设没有其他相关窗口、标签页或应用页面继续运行。

当前判断

具备采集条件，仍需接口调用成功。

有效敏感权限有（假设）
新照片 / 录音 / 位置可能采集

代码运行、设备可用、系统许可与安全上下文均满足时，页面可调用获准接口；已有授权不代表每次都重新弹窗。基础信息通常不依赖这些敏感权限。

已经上传到服务器的数据，不会因关页或撤销权限自动删除。

切后台 ≠ 关闭

已有媒体采集可能继续；移动系统、节能和浏览器策略可能暂停或限制。不能把最小化、锁屏或切应用作为可靠的“已停止”证据。

保留权限 ≠ 后台驻留

真正卸载页面后，其媒体源必须停止。浏览器可能保留授权供再次访问使用；本仓库没有因此变成后台常驻监控程序。

后台任务有自己的边界

Service Worker 可处理推送、同步等有限事件，但不能凭已保存的相机 / 麦克风权限在关页后继续调用窗口的采集接口。已排队请求可能在关页后完成，不等于采集新数据。

W3C 媒体源生命周期 · Service Worker · Chrome 临时与保留授权

如何让下一次访问也必须重新询问？

在浏览器的网站权限设置中找到对应站点，将摄像头、麦克风、位置等设为“询问”或“阻止”；确认相关页面已关闭。不同浏览器菜单名称不同。仅清理历史记录不应被当作一定撤销权限；撤销权限也不会收回服务器已经保存的数据。

08 / QUESTIONS WE ASKED

把讨论中的理解，逐一校准。

它就是收集浏览器能访问的所有信息，然后上传吗？

更准确地说，是收集“作者编写了逻辑、接口确实提供、当前权限与环境允许”的那部分数据。它没有实现浏览器能力图谱中的全部项目。现有代码主要通过 HTTP 请求上传，没有看到特殊的其他传输机制。

本质上就是想取得用户的一些权限？

是的，敏感采集部分依赖用户授予该网站的相机、麦克风或位置权限；同时还会尝试读取无需弹窗的环境信息。这些是限定范围的网站权限，不是用户账户管理员权限，也不是整机控制权。

不点任何“允许”，就一定没有信息被收集吗？

不是。请求本身就可能暴露出口 IP 与访问时间；页面还可读取部分环境信息和本站交互。若此前已为同一来源保存了有效授权，这次没有弹窗也不代表没有敏感权限。

“无论如何都拿不到”这个说法准确吗？

不准确。需要限定普通网页和正常浏览器安全模型。不能直接读取聊天数据库，但用户共享整个屏幕时可能暴露聊天画面；不能扫描相册，但用户选中的照片可能带有位置元数据。数据来源和授权路径必须分开讨论。

位置来自 GPS 吗？知道 IP 就知道住址吗？

网页拿到的是浏览器 / 系统提供的定位结果，来源可能结合 GPS、Wi-Fi、蜂窝或其他定位服务，网页不能保证来源和精度。IP 通常只能用于粗略地域推断，代理、VPN、移动网络出口都会影响结果。

关掉网页是不是就完全没影响了？

真正关掉采集页面会终止其采集，但持久权限可能还在，下次访问可能再次使用；服务器已经保存的数据也不会自动消失。切后台、最小化和锁屏都不能简单等同于关闭。

授权后可以永久悄悄监控吗？

不能这样推断。页面生命周期、授权期限、设备与操作系统策略都限制采集；相机和麦克风有使用指示。Service Worker 的后台事件能力也不等于可以在关页后继续访问这些媒体接口。

隐私模式或 VPN 可以阻止全部采集吗？

不能。隐私模式主要改变本地数据保留和隔离方式，不会让网站看不到当前访问；VPN 主要改变网络出口，不会撤销摄像头权限，也不会阻止你主动提交表单或文件。具体保护依赖浏览器策略。

这个研究网页本身会采集信息吗？

本页面仅包含本地筛选、流程解释和情境切换；不调用相机、麦克风、定位、剪贴板，不上传数据，不嵌入分析服务或第三方脚本。像任何网站一样，托管服务器仍会接收加载页面的常规请求；主动打开外部来源链接会访问对应网站。

可以把上游代码直接拿来商用吗？

本次检查的上游版本未发现 LICENSE 文件，GitHub API 未识别许可证。公开可见不等于获得任意复用、修改或分发授权。需向作者确认；本项目仅原创解释并链接上游源码，不复制其工具、页面模板或截图。
