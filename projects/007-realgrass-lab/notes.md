### 独立实现

1. 原生 WebGL2，不引入 Three.js 或其他运行依赖。
2. CPU 根据种子与实例 ID 生成有限范围叶片；默认 56,000 片，每叶 4 段、8 个三角形。
3. 实例记录 8 个 float（32 B）：位置、形态、相位、颜色变化、花朵标记与宽度。花朵实例另有缓冲。
4. 顶点阶段根据位置与时间计算草浪，用当前笔刷的径向位移表达拨动；未保存逐叶速度或多处笔刷历史。
5. 天空采样二维云平面，地面与草叶用同一噪声场计算投影云影；阵风受云场调制。
6. 最多 3 次绘制调用：背景（含地面）、草叶、花朵；关闭花朵为 2 次。
7. 相机支持拖动转向、滚轮前后移动、键盘方向 / WASD 移动、草地 / 近看 / 俯瞰预设。
8. 切换到自研版卸载外部 iframe；自研画面离开视口、页面隐藏或退出时停止其动画帧调度。

### 差异与结论

自研方案证明：有限范围的草地氛围、可见的草浪、花朵、局部拨动与共享云影，可以通过实例化与解析函数组合获得。它没有证明原库系统冗余，也没有证明自研性能更优。

当需求涉及逐叶持续状态、大范围移动、近远景连续与体积云穿行时，原库更复杂的数据流针对的是这些额外能力。选型应先明确这些需求是否存在。

其他路线的分析把图形接口、封装引擎、运动模型和天空渲染拆开；它们可以组合。路线建议是工程判断，不是本轮实验跑分。

### 未验证事项

- 没有同设备、同视角、同分辨率的原库 / 自研 GPU 时间基准。
- 没有运行上游的完整 CPU / WebGPU 自动回归。
- 没有验证移动设备硬件性能；窄屏布局测试不等于手机 GPU 测试。
- 没有实现 Canvas、Transform Feedback、WebGPU、Unity / Unreal 或 Mesh Shader 的第二份演示。
- 不支持与跨域原库同步相机 / 参数，也未读取原库内部诊断对象。
- 图形上下文丢失与不支持 WebGL2 的错误界面有实现，本轮未注入故障测试。
