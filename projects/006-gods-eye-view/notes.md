- 无 API Key 模式不验证付费地图、AISStream 船舶和 AI 语音。

### 解释边界

1. 飞机图层连接第三方公开服务，界面动效与真实数据可以共存；影像中停机坪的飞机不属于实时图层。
2. 13.0K 为全球加载数量，不能理解为上海区域飞机数量。单次区域零记录也不能推断所有时段、所有中国区域均无数据。
3. OpenSky 在本次过程先超时、后成功，说明外部可用性存在波动；未进行持续运行或跨运营商测试。
4. 地球底图可以浏览，不代表具有实景三维建筑、实时卫星视频、全国船舶或摄像头覆盖。未配置凭据的能力没有作为成功项目计入。
5. 未运行上游完整自动化测试套件；本次验证覆盖安装、环境诊断、真实浏览器交互和航班服务端响应，上游源码保持原样。

### 本次后台运行

交付时服务以隐藏进程运行，PID 记录在忽略目录 `app/.logs/server.pid`。日常运行建议使用 `start.cmd`，在终端按 Ctrl+C 停止。后台进程仍存在时可直接访问本地入口，无需重复启动；重启电脑后重新运行启动脚本。
