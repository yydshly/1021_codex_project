# 研究记录

## 2026-10-20 · 用 Remotion 实现扁平矢量 MG

### 问题与方法

验证能否用 AI 编写 Remotion 动画，在本地输出一支完整的 10 秒 MG 视频。参考 mg-styles-15 的风格特征，采用原创分镜、文字、几何图形与合成音频。

Remotion 与 CLI 统一锁定为 4.0.537。每帧画面只由帧号计算，字体先通过 FontFace 加载，再放行渲染。没有依赖真实时钟或 CSS 实时动画。生成音频使用固定种子 1021。

### 环境问题

- npm 首次安装漏装了 Rspack 的 Windows 原生可选依赖。以明确版本补装 `@rspack/binding-win32-x64-msvc@1.7.11`，不修改全局 npm 配置。
- TypeScript 的字体集合类型需要 `DOM.Iterable`；已添加并通过类型检查。
- 完整 Noto Sans SC 字体仅用于生成子集，不纳入项目提交。随项目保存约 53 KB 子集与 OFL 许可。

### 验证记录

- `npm run typecheck`：通过。
- Remotion 4.0.537 完整渲染成功，Google Chrome 无头模式，3 个并发任务，PNG 帧输入，H.264 CRF 16、BT.709、yuv420p。
- 封面来自 Remotion 第 265 帧，`assets/contact-sheet.jpg` 从最终 MP4 提取，时间点对应第 0、18、45、85、110、145、180、205、235、265、299 帧。
- 已目视检查关键帧：中文字形正常，无文字裁切；修正了初版开场拱形与圆形挖空部分不同步的问题。
- ffprobe：1920×1080，30/1 fps，300 个视频帧，画面 10.000 秒；AAC 48 kHz、2 声道，音轨及容器 10.005 秒（末包填充）。
- 文件大小 1,364,746 字节。
- FFmpeg 对成片完整解码：退出码 0；blackdetect（最短 0.05 秒）没有报告黑帧。
- 对最终 AAC 音轨测量：综合响度 -16.06 LUFS，真峰值 -1.15 dBTP，响度范围 1.30 LU。此结果为数值检查，未声称完成主观试听。
- 导出时同时启动 still 和 render 曾产生 Webpack 缓存写入警告，两项均退出码 0；复现时建议按 README 顺序运行。
- PowerShell 环境中的 `npm.ps1` 未正确转发部分 `npm run ... -- ...` 参数；README 使用实测通过的 `npx remotion ...` 完整命令。

### 设计边界

- 这是 10 秒风格试片，尚未实现可通过表单替换所有内容的模板系统。
- 配乐为轻量合成音乐，无配音、真人采样或外部音乐素材。
- 使用弹性曲线和形状遮罩，未启用多样本运动模糊。
- 未进行与 mg-styles-15 或其他渲染工具的性能对比。
- 作品目前以四个场景展示风格；相比完整商业叙事，角色动作与画面间的故事联系仍较简单。后续可针对具体产品补充分镜、旁白和更连续的物体变形。
