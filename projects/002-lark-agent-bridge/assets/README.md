# 研究图片与网页截图

`understanding-map.png` 为 2880 × 2040 的原创中文技术信息图，汇总库的能力、工作原理、适配器和未来价值。

`understanding-map.svg` 是同一张图的可编辑矢量版本。绘图源码在 `../app/generate_infographic.py`，使用 Pillow 与 Windows 微软雅黑字体进行精确排版，同时输出 SVG；字体文件没有复制到仓库。

`infographic-prompt.txt` 保存四模块设计简报。内置生图尝试两次均因网络错误失败，最终成图由程序绘制，并非模型生图结果。

`cover.png` 为本项目研究网页“适配器”章节的真实桌面浏览器截图，用于子项目 README 和总目录展示。

`mobile.png` 为研究网页在 364 像素宽浏览器视口下的真实首屏截图。

截图展示解释性网页，不代表上游机器人已经部署或实测。网页架构图由 HTML/CSS 原创绘制，无第三方品牌素材。
