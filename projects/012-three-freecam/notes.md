# 研究记录

## 2026-10-22 · 第一阶段：先展示真实效果

### 实现与来源

上游 main 为 6988dee89080c29d7cfbe9abbab879e1fd972996，许可证 MIT。使用 npm three-freecam 0.2.0、Three.js 0.186.0。原创观景塔、拱形连廊和圆环用于展示视角、距离和透视变化。

链路：本地静态 HTML → 打包的 Three.js / FreeCam → 输入事件 → 相机 → WebGL。无 API、数据库、CDN、登录。

### 事件级验证

app/verify-controls.mjs 导入真实安装的库，以 EventTarget 作为 DOM 监听目标并派发事件，不重写控制算法。

运行 npm run verify:controls，9 项通过：

1. W 移动距离等于速度乘时间。
2. 右拖输入改变四元数。
3. Alt 环绕改变位置，并保持到 pivot 的距离。
4. 中键输入产生平移。
5. 普通滚轮推拉。
6. 右拖时滚轮调速。
7. Object3D 聚焦使 pivot 对齐中心。
8. 惯性开启后松键仍有衰减移动。
9. 禁用后停止更新位置。

这些检查不覆盖真实 Pointer Lock 权限，也不等价于跨浏览器和真机测试。

### 实现修正

- 本地打包全部依赖，避免 CDN 加载失败。
- 场景焦点门控与失焦清键，避免滑块、弹窗和场景输入冲突。
- 禁用上游默认 F，接入实际射线选中项。
- 窄屏增大视场角，并按水平视场补充聚焦距离。
- 自动巡游使用 FreeCam.placeAt/update，未引入第二套控制器。

## 2026-10-22 · 能力与价值总结

根据进一步讨论，本库的价值主要是封装基础相机交互、减少重复开发，不带来建模、画质提升或内容生成能力。对当前研究展示与内容创作价值较低，暂不深入投入；需要三维编辑器、巡检或自由漫游时再复用。
