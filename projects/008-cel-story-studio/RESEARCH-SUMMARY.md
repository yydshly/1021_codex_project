# MG风格与故事创作：研究总结

研究收尾日期：2026-10-22。状态：**研究收尾归档，现有演示可继续使用**。0.19汇总整理已有结论、资产与使用边界，暂不增加新作品或继续扩展生成能力；影片与独立源码包保持0.18基线。

## 核心结论

这套工作台是**由故事和分镜组织、由程序执行的动画制作系统**。其过程为：

**创作目标 → 故事与分镜 → 图片/矢量/三维资产 → 动作、镜头和材质程序 → Remotion逐帧合成 → 完整审片与返修。**

当前没有接入文生视频、图生视频模型。AI可提出创意与结构化方案，也参与部分静帧的制作；每一帧的运动主要由已实现的动画程序计算。新作品通常需要定制资产和动作，已有作品则可在其参数与事件范围内改编。

研究对象 `mg-styles-15` 提供十五组风格提示、源代码与演示，形成视觉参考与制作约束。研究它们有助于明确目标效果和实现方法；不能据此把十五组提示当成已经安装的十五个独立Skill，也不能把参考视频当作可编辑模板。本项目保留原作，并为自己的题材另做实现。

[能力与理解全景图](assets/capability-map-019/mg-styles-capability-map.png)将源库、我们的实践、十五种效果、复用方式与边界放在同一张图中。[下次制作指南](NEXT-VIDEO.md)把这些结论落实为可复制简报、入口决策和六步制作流程。

## 源库展示什么效果，适合什么场景

源库的可见能力是通过十五个具体作品展示视觉语言与制作方法。提示词说明目标与约束，源码展示对应实现，成片提供效果参照；它没有为任意输入内容提供统一的视频生成接口。我们提炼的是可迁移原理，不把原作直接当作我们可编辑的素材模板。

| 风格 | 典型动态效果 | 适用场景 |
| --- | --- | --- |
| 扁平矢量 | 几何弹跳、挤压拉伸、色块转场 | 品牌片头、功能说明 |
| 线条动画 | 连续描线、路径延续与转场 | 极简品牌、流程说明 |
| 等轴2.5D | 微缩城市生长、模块装配 | 系统架构、园区物流 |
| 3D渲染 | 软体回弹、材质光影与重量感 | 产品质感、发布片头 |
| 逐帧手绘 | 沸腾墨线、逐格节奏与手工纸感 | 温暖故事、文创教育 |
| 拼贴剪贴 | 纸片并置、尺度反差与定格摆拍 | 文化栏目、音乐视觉 |
| 液态流动 | 液滴融合、拉伸与字形聚合 | 美妆饮料、品牌聚合 |
| 形变动画 | 轮廓连续变换、物件无缝衔接 | 功能关联、标志演绎 |
| 几何包豪斯 | 网格翻转、排列与节拍编舞 | 动态海报、系列识别 |
| 复古霓虹 | 透视网格、霓虹辉光与复古电子质感 | 电子音乐、游戏活动 |
| 极光玻璃 | 渐变光场、通透表面与透镜折射 | 软件发布、界面展示 |
| 综艺花字 | 弹跳字幕、反应剪辑与情绪符号 | 生活短片、访谈包装 |
| 贴纸科普 | 贴纸图解、大画布平移与缩放 | 知识解释、产业介绍 |
| 像素动画 | 像素角色、关卡结构与冒险节奏 | 游戏宣传、怀旧营销 |

源库按效果选用SVG、Canvas、WebGL、Three.js、Blender/Cycles和帧序列合成等技术；Remotion是我们后续实践的时间轴与输出选择。HUD的视觉表现不等于真实目标监控，液态画面也不能据外观推定采用真实流体解算。风格的构图、材质、动作与节奏要共同成立，单纯换色不足以迁移整套表现。

## 对我们的意义与沉淀方式

价值在于减少反复从零摸索：先有可见目标，再知道需要设计什么、实现什么，以及在哪里修改。沉淀依次经过**拆解视觉机制 → 独立题材制作 → 参数与接口整理 → 用不同故事验证 → 固化资产、规则和审片案例**。一支作品的独特设计不能未经验证就归为通用组件。

每次保留五类东西：创作方法、风格规范、资产与动画组件、数据契约与制作管线、作品及质量证据。下次先从这些已验证范围中选择，未覆盖的角色、动作、声音或交互另行制作；完成后将有效修法再回流到能力库。具体步骤与交付清单见 [NEXT-VIDEO.md](NEXT-VIDEO.md)。

### 可扩展的产品方向，尚未通用实现

| 方向 | 可复用基础 | 继续产品化需要补什么 |
| --- | --- | --- |
| 品牌短片模板工具 | 几何、形变、三维材质与可编辑参数 | 授权品牌资产接入、版式约束、系列一致性 |
| 知识解释视频工具 | 线条、科普图解、空间结构与镜头方法 | 事实校验、可替换机制图、数据与字幕接口 |
| 有限资产故事创作器 | 角色包、事件词表、镜头和情绪控制 | 更多可验证的动作、接触关系与故事骨架 |
| 批量与多语言版本 | 确定性配置、预览和渲染流程 | 长文本适配、字体、配音、音画配时、任务管理 |

这些方向优先复用已有方法与实现，不能只增加风格或情绪选项就获得任意故事的高质量自动制作能力。

## 情绪、风格和技术各负责什么

| 层次 | 作用 | 可沉淀内容 |
| --- | --- | --- |
| 情绪与表达目标 | 说明希望观众感受到什么，如胆怯、安心、发现或获得辽阔 | 有具体行动支撑的创意、情绪转折和案例 |
| 导演与分镜 | 把意图落实为事件、景别、动作顺序、停顿和配时 | 经过作品验证的分镜方法、镜头/表演规则与适用条件 |
| 风格与美术 | 规定轮廓、色板、笔触、材料、光线与空间组织 | 风格规范、角色、场景、道具、纹理和材质 |
| 动画实现 | 准确执行位置、关节、轨迹、接触、遮挡、形变和镜头 | 可调用的实现、共享锚点、参数契约及状态继承方法 |
| 制作与验收 | 预览、修改、保存、输出、完整播放和返修 | 确定性管线、配置、版本对比及问题/修法记录 |

情绪是输入，风格是表现规则，技术是执行手段。真正有价值的积累，是它们之间已经在实际影片中成立的连接方式，而不是增加一个情绪选项就自动获得好表演。

以小鲸的“胆怯”为例：五秒跃入镜头可先停约0.65秒，降低跃幅、放慢尾鳍，再进入海面。当前程序已实现这组变化，但它属于这套狐狸/鲸资产与事件设计；不意味着换一种角色、动作或情节仍能直接沿用全部数值。

## 已实现能力的四条路径

### 故事导演演示：一套完整、专门制作的资产包

入口：`#flagship`。作品为《给你一片海》及一次真实AI改写《给你一片星海》，各20秒、1920×1080、30FPS。

狐狸、小鲸、画笔、墨碟、工作室和海面共同完成五个固定依赖事件：**发现 → 绘画 → 展开 → 跃入 → 告别**。手掌、笔尖与墨迹共享几何关系，纸页展开与角色落点保持连续；镜头、姿态和局部水纹由程序执行，环境图本身不是流体视频。

可调整标题、称呼、强调色、声音、每镜景别/情绪/字幕/时长，以及海洋或星海结尾。每镜1.5–8秒，半秒步长，全片12–30秒。五个事件与顺序固定。AI提出方案后经校验，由用户审核应用；当前AI改写保持称呼、强调色、声音与总时长。

这条路径验证的是**同一故事骨架与美术资产内的重编排**。故事简述是创作记录，真正执行的是已定义的字段；没有逐句自然语言自由生成任意表演或新素材。

### 十五种独立效果模板：按各自机制制作和复用

入口：`#styles`。保留十五支完整样片、原作、修改前版本、关键帧及参数模板。支持文字、配色、各模板参数、种子、时长、声音、预览、JSON保存/导入与MP4输出。

| 当前实现类别 | 对应风格 | 主要边界 |
| --- | --- | --- |
| Canvas逐帧绘制 | 扁平矢量、线条、手绘、拼贴、形变、包豪斯、花字、贴纸科普、像素 | 使用各自设计的轮廓、对象与事件；不是任意资产自动风格化 |
| Three.js三维场景 | 等轴2.5D、霓虹、HUD | 有限模型、灯光、相机和动作程序 |
| WebGL三维SDF曲面 | 液态 | 艺术化曲面与光照，不是真实流体物理解算 |
| WebGL内容采样折射 | 极光玻璃 | 屏幕空间近似，不是多次体积光追 |
| Blender/Cycles最终材质渲染 | 3D质感 | 默认成片缓存；修改后使用快速构图预览，最终导出需离线重渲染 |

手绘、形变、玻璃、线条、科普五项各有两套人工设计故事，选择故事时同时更换相应对象、行动或任务。霓虹、像素、HUD三项开放2–8镜头的手动及AI编排，每项使用自己的四种已实现动作；全片4–20秒。它们仍沿用有限资产组，不新增任意模型、精灵或情节。

五项双故事与三项AI编排是不同能力，不能将数量合并成“十五种风格都支持任意故事生成”。

### 原有故事世界：AI生成受约束的矢量资源

入口：`#main`。这条路径与旗舰示例、十五种独立效果模板分开。

AI可设计结构化角色、场景、道具和动作关键帧；角色与布景由椭圆、矩形、多边形和线组成，经校验后交给通用矢量渲染器。世界支持1–3角色、1–4场景、0–8道具、1–10镜头、1–60秒，以及移动、拿起、放下、递交、推动和自由表演等行为。持有物件和角色落点可跨镜继承。

这比固定角色模板更开放，但图形、骨骼、交互和效果均受schema与运行时约束。手部接触采用通用近似，不能生成照片级人物、任意物理或精细传统原画。世界模式的风格适配器与独立效果引擎不同，部分3D、玻璃等表现是二维近似。

### 原有故事叠加组件：有限、可组合的画面增强

入口：`#story-styles`。保留17个Canvas共享组件，如纸感、行动轨迹、镜头推近、情绪花字、步骤标记和主体追踪框；每个故事最多选6项，强度0–1。配置可随故事保存，组合可在本浏览器另存。

这些组件读取已有故事状态并增强表现，不为角色创建新动作，也不等价于十五种独立效果模板的完整工艺。

## 从头到最终效果的控制点

| 阶段 | 要控制的内容 | 可检查的产物 |
| --- | --- | --- |
| 明确目标 | 谁想得到什么、通过什么行动改变局面、最后留下什么感受 | 创意与情绪转折、关键画面设想 |
| 分镜设计 | 事件因果、景别、表演、空间位置、停顿与时长 | 人工或AI提出的结构化镜头方案 |
| 资产准备 | 角色一致性、场景尺度、道具、材料和风格统一 | 资产包、姿态与构图关键帧 |
| 动画实现 | 手与工具、工具与轨迹、角色与地面、水面遮挡、状态继承 | 动画函数、共享锚点和受校验配置 |
| 预览与输出 | 同一配置驱动预览及逐帧合成，字体/素材/音频加载可靠 | 可编辑项目、MP4与实际编码抽帧 |
| 审片返修 | 动作可读性、重量、连续性、节奏、材质与声音 | 完整影片、具体问题、修改前后证据 |

参数确定并不等于艺术质量确定。测试能检查格式、计算和输出链路；“是否动人、是否有惊喜、是否像一个完整作品”仍要看实际成片，并在对应层返修。

## 已验证结果与仍然存在的边界

0.18记录了实际AI请求与返回、方案审核应用、独立草稿恢复、镜头选择及景别修改、撤销、无效标题保留有效预览、浏览器1080p导出与完整播放。两支成片和网页导出各600帧，完整解码；十五支既有影片及73份历史归档文件通过哈希保留检查。独立包实际安装258个依赖、类型检查并渲染第420帧。记录位于 `assets/review-018/`。

艺术审看修正了相机露底、笔碰口鼻、脚底悬空、墨线与海面脱节、水面矩形补丁、鲸移动方向和墨碟残影等具体问题。仍有角色/环境笔触密度不一致、身体表演较单一和海景本体偏静态的问题。十五种风格的质量与复用成熟度不相同，没有判为全量优秀。

目前未实现或未充分验证的事项包括：

- 任意自然语言故事自动生成同等质量的角色、场景、动作与完整影片。
- 任意照片/视频/三维资产上传、精细手指和骨骼编辑、通用物理与真实流体解算。
- 全风格通用的角色/事件替换、专业声音设计、配音、口型和竖屏生产流程。
- 独立包整片渲染、0.18原生JSON文件选择器交互，以及专业主观听觉审片。

此列表为保留缺口，不是本轮承诺继续开发的任务。归档表示研究暂告一段落；恢复研究时，按具体用途选择缺口，而非继续无边界增加效果。

## 运行、维护与验证

本地服务默认仅监听 `127.0.0.1:8048`。在 `app/` 执行 `npm ci`、`npm run build`、`npm start`；已有依赖时可用项目根目录 `start-workbench.cmd`。网页总结入口为 `#overview`，已有路由与历史页面保留。

AI使用本机已登录Codex CLI连接模型服务，需要网络和账户可用额度。支持 `CEL_CODEX_PATH` 指定CLI路径，`CHROME_PATH` 指定浏览器，3D自定义最终输出可用 `BLENDER_PATH` 指定Blender 4.5+。网页不提供通用API Key或任意厂商切换。

静态 `web/` 可浏览、手动预览和下载已有作品；AI创作与新视频生成需运行Node服务。不要直接双击HTML。修改网页后重建并刷新；修改影片源码后还需重启服务，使渲染端重新打包。普通浏览无需重渲染影片。

应用检查为 `npm run typecheck`、`npm test`；0.19汇总整理已通过类型检查、77项应用检查、8项仓库检查和索引校验。网页复核了分类、编辑入口、旧研究锚点和草稿恢复，同时修复了空代码分包的HTTP响应。41个原作、成片与能力包文件保持不变；本轮未调用AI或重新渲染影片。[0.19实际验收记录](assets/review-019/verification.json)将这些工程结果与既有影片的艺术质量分开记录。

媒体重渲染脚本、真实AI生成脚本和独立打包脚本保留在 `app/scripts/`；真实AI脚本会调用模型并消耗请求，部分研究脚本还会覆盖指定样例，因此不作为普通离线检查或归档清理步骤执行。
