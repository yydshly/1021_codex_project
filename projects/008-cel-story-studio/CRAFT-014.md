# 先完成作品，再沉淀能力 · 0.14

前面我把“覆盖十五种、能运行、能改参数、能导出”多次当成阶段完成，对画面质量的判断偏松。先套统一模板再填风格，导致手绘少了表演、拼贴少了材料关系、形变少了部件交接、玻璃少了真正穿字折射。迭代花在题材替换、参数和平台功能上，却没有及时修复这些核心缺口。这是制作目标和验收顺序的问题，不能归因于 Claude 或 Codex 的名字。

## 怎样生成更好的作品

1. **先定一个值得看的事件**：一句话写出谁想做什么、遇到什么阻力、画面最后如何改变。 没有可见矛盾与结果，就不开始写模板。

2. **先画最后一张海报与6–8张关键画**：审主次、剪影、材质尺度和视觉高潮；形变还审三个过渡中点。 关键画不好看，先改原画和构图。

3. **准备风格专用资产**：手绘要完整姿势；拼贴要分层和铰链；3D要近景几何、反射环境；花字要字形与情绪。 素材不具备所需表演结构，不用整体平移凑动作。

4. **用事件表组织画面和声音**：写清预备、接触、受力、停顿、回弹与转场锚点；相机与主体共用时钟。 每个动词必须在画面里真实发生。

5. **按事件选择实现技术**：Remotion负责逐帧时间和输出；Canvas、矢量、WebGL、Three.js、Cycles各自解决适合的镜头。 不以技术名称、采样数或模型名称代替画面判断。

6. **看关键帧，也看连续帧**：遮字幕读故事，检查接触和转场前后；看手机版尺寸和最终H.264。 失败就改具体镜头，而不是加颗粒、辉光和按钮。

7. **作品成立后再沉淀复用接口**：抽出已成功的姿势、路径、材质、镜头和内容参数，记录真实边界。 可参数化不等于任意故事自动生成；技术通过不等于审美验收。

## 为什么源作更好

源作把视觉语言落实为具体资产、事件、镜头和最终版式：同一锚点贯穿变换，动作有预备与受力，材质随事件变化，稀密与停顿有节奏，结尾能成为独立海报。提交的代码与成片证明这些工作实际做了；提示词只是目标说明，不能替代制作和审片。
