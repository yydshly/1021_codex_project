# 下次制作类似MG视频：从简报到可复用成片

这份指南用于复用本轮研究成果。源库 `mg-styles-15` 提供风格提示、源码和成片参照；我们的工作台提供另外制作的模板、资产、动画与控制流程。当前未接入文生视频或图生视频模型，也没有任意故事自动适配十五种风格的通用系统。

匹配的是对象、事件和表达机制。不能因为两个作品都叫“手绘”或“3D”，就假设素材和动作可以直接替换。

## 一份可以直接复制的创作简报

```text
这次要为【受众】制作【品牌/产品/知识/故事/活动】视频。
用途和发布位置：【具体渠道与观看情境】。
时长与画幅：【秒数；横屏/竖屏；目标分辨率】。
核心信息：观众看完应记住【一句话】。
情绪目标：从【起始状态】到【结束状态】，通过【具体行动】表现。
故事：谁【角色】想得到什么【目标】，遇到什么【阻碍】，怎样行动【因果事件】。
风格与参考：【风格名称；参考作品；喜欢的具体质感/动作/镜头】。
视觉高潮：在【时刻】看见【关键画面】；结尾留下【画面/短句】。
已有可复用内容：【模板、角色、场景、道具、动作、材质、声音】。
需要新增或修改：【新资产/新动作/交互/镜头/声音】。
文字与事实来源：【字幕、品牌词、数据及出处】。
声音要求：【配乐/音效/旁白；授权来源】。
交付：【MP4规格、配置JSON、源码/资产范围、版本】。
质量参照：【要达到的具体画面与动态标准；哪些问题不可接受】。
```

简报中可以提出当前未支持的竖屏、配音或复杂表演要求，但应把它们列为新增制作任务，不能据此视为工作台已有功能。

## 六步制作流程

### 1. 写简报，确定表达目标

先写观众、用途、核心信息与情绪转折，再决定长度和视觉语言。将“更高级”“更温暖”等描述转成可观察的行为，例如“角色先停顿观察，再小心递出道具”；这种行为才能进入分镜和动画实现。

产物：一份简报和一句核心表达。事实、品牌和授权素材由实际资料支持，不用示意动画代替事实依据。

### 2. 选风格与已有入口，核对复用范围

完整观看源库参考片与我们的对应成片，判断吸引力来自选题、材质、构图、动态还是音画节奏。对照上表选择入口，列出“能直接用、需要调整、必须新增”三类内容。保存一份已有配置或复制独立工程，保留原始版本。

产物：风格参照、起点配置与新增制作清单。不要仅因颜色相似就判为已经匹配。

### 3. 设计因果分镜和关键画面

安排角色目标、预备动作、主要行动、回应与收束，标注景别、画面重心、空间位置、字幕和配时。先确认开场识别、视觉高潮、结尾三类关键画面，再推进完整动画。已有模板只在其事件与控制范围内编排；不支持的行为先设计实现方案。

产物：结构化分镜和关键帧。动作必须能读懂，镜头切换要延续位置、道具状态和事件结果。

### 4. 复用资产与组件，补齐新的制作

选择角色、场景、道具、轮廓、材质与声音，保持同片风格一致。复用已有动作、路径、相机、转场和参数；新增交互要考虑手与工具、工具与轨迹、角色与地面的接触、遮挡和跨镜状态。复杂三维材质或模拟按需要选择适合的技术，不要求所有效果都由同一种引擎完成。

产物：有来源说明的资产包、动画实现和控制项。可调用范围应由代码与数据契约说明，不能只保留一句风格提示。

### 5. 用同一配置预览与输出

先检查素材、字体、镜头和声音能否可靠加载，再调节动作与节奏。线上可浏览、编辑预览、保存JSON和下载已有作品；AI编排与生成新MP4需启动本地Node工作台。线上与本地草稿按站点隔离，先保存JSON再导入本地。自定义3D最终材质成片另需Blender。

已有依赖时使用项目根目录的 [start-workbench.cmd](start-workbench.cmd)；完整安装步骤见 [README](README.md#本地运行与维护)。离线工程可从 [独立包](web/director-kit-018.zip)开始，具体运行方法见包内README。不要把账户凭据、私人日志或依赖目录加入交付。

产物：可继续修改的配置/工程与MP4。生成成功只是工程结果，下一步仍需审片。

### 6. 完整观看、返修，再回流到能力库

从头到尾看实际导出的影片，检查动作与文字是否可辨认、接触和空间是否连续、节奏是否形成起伏、材质是否统一、声音是否合适。将问题归到选题、分镜、资产、动画、合成或声音层，修改后再次完整观看。

有明显缺口时保留“待修”状态。对照源作和上一版说明具体改变，不能用测试通过、渲染完成或自定分数代替艺术判断。最终把本次有效方法、组件、限制和失败案例回流保存，下一次才能减少重复探索。

## 每支新作品应该留下什么

| 应留下的内容 | 最低记录 |
| --- | --- |
| 表达与导演方法 | 简报、分镜、关键画面、情绪变化如何通过行动呈现 |
| 风格规范 | 构图、配色、笔触、材质、光线与运动节奏，以及适用条件 |
| 资产与动画 | 角色/场景/道具来源、可复用动作与组件、新增实现及依赖 |
| 制作契约 | 最终配置、参数含义、允许范围、状态关系和运行方法 |
| 交付与质量证据 | 完整成片、关键帧、原作/前后版本链接、问题及有效修法 |

建议保留一个明确的质量基准：**最终MP4＋对应JSON＋核心关键帧＋已知限制**。资产、配置和代码应能说明这支片如何生成；下一支片沿用后，也要用新的对象或故事验证，而非只验证旧样片还能运行。

## 本轮成果与下一轮任务的界线

可以立即带走创作方法、已有资产、动画/材质实现、受校验配置和预览/输出流程。品牌模板工具、知识解释工具、有限资产故事创作器、批量与多语言版本是后续方向，需要各自的内容接口、资产、字体/配音/配时和质量验证。

当前没有任意资产上传、全风格角色互换、通用流体物理或任意故事同质量生成。研究先归档；下一次根据具体简报补最必要的一段能力，完成实际作品后再扩大复用范围。
