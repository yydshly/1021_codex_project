## 工作台中的呈现

- `#effects-gallery` 默认展示原创作品的大封面，保留“原作对照”切换。
- 点击封面先进入完整样片放映；“编辑这个样例”再载入该片的完整配置，避免浏览时覆盖草稿。
- 顶部提供十五支影片的 45 秒精选合集；每支完整影片仍为 10 秒。
- 旧的实时编辑、内容／配色／参数、原作同步对比、保存／导入与 MP4 导出保留。配乐新增可关闭开关。
- 修改文字不会自动重建主题几何；主题模型仍是模板的设计资产，任意 AI 故事自动编译到这些模型仍未实现。

## 视觉审看方法

先审看十五支片的实际关键帧，再检查完整输出的运动和首尾。重点包括主体层级、字与图的遮挡、材料是否可辨、地面与物体接触、素材裁切，以及参数是否真正在画面中生效。类型检查和像素差异只能证明实现正常，不用来证明审美“优秀”。

本轮关键帧审看修正了温室屋顶朝向、图集裁切串入相邻素材、月面过强清漆高光，以及灯轨和玻璃边缘过曝。上一版封面保留在 `assets/effect-before-v08/`，用于比较本次实际变化。

## 实现与复现

代码位于 `app/src/effects/canvas-v2.ts`、`three-v2.ts`、`shaders-v2.ts`，由 `EffectScene.tsx` 统一提供给浏览器与 Remotion。`art-directions.mjs` 记录十五项新题材、机制、参数和边界。新图像及完整提示词见 [GENERATED-ASSETS.md](GENERATED-ASSETS.md)。

```powershell
cd projects/008-cel-story-studio/app
python scripts/make-effect-scores.py
npm run build
npm run render:effects
python scripts/make-effect-reel.py
python scripts/verify-effect-media.py
```

本轮三维使用实时 PBR、透射、阴影与 Bloom；液体和折射使用 GPU 着色器。未接入 Blender 离线渲染、真实流体解算或照片级角色表演，不声称与源库全部工艺等价。

## 本轮验证记录

- 十五支默认影片均为 10 秒、300 帧、1280×720、30 fps，H.264 + AAC；FFmpeg 完整解码通过。每项另有基准、运动、参数、内容／颜色四帧，共 60 帧；45 组主体区域差异通过。
- 浏览器逐项点击十五张封面，等待「影片已就绪」后，十五项均为 `readyState=4`、`paused=false`、1280×720、无媒体错误。45 秒精选也在浏览器实际开始播放。
- 从网页修改三维样例为《轨道之间》、9 个节点、6 秒并开启配乐，实际导出任务 `4250acf7-e05c-4945-ac53-bd411d6b0d2b`；提交快照与下载的 JSON 相同，180 帧 H.264 + AAC 完整解码通过。文件保留在 `web/creative-examples/amber-6s.*`。
- 「原作对照」切换后有 15 张原作封面；有效宽与页面宽均为 658 px，无横向溢出。观看影片后返回故事，《阳台上的小花》、小禾、5 镜／12 秒，以及四项叠加组件和强度保留。
- 五段原创合成音乐均有有效信号，峰值小于 0.36，未削波。48 项应用测试、类型检查、构建及仓库检查通过。
