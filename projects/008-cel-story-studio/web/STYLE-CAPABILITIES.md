# 风格能力库

以故事表达为目标，沉淀视觉语言、运动方法和可复用组件。15 种基础画法均为探索原型；下列扩展项尚未实现。

## 工作台复用

打开「风格能力库」→ 研究风格 → 采用推荐组合或只切换基础画法 → 选择共享组件、调整强度 → 预览并导出。组合可以保存到本浏览器，完整故事 JSON 同时保存 recipe；载入故事会保留组合，导入配置则恢复该配置自己的组合。AI 创作接收表达规则与选定组件，不得自行更换组合。

配置示例：

```json
{
  "style": "cel-boil",
  "recipe": {
    "version": 1,
    "components": [
      {
        "id": "paper-grain",
        "amount": 0.35
      },
      {
        "id": "ink-border",
        "amount": 0.5
      }
    ]
  }
}
```

每个故事最多 6 个附加组件，强度为 0–1。未提供 recipe 的旧故事保持原有表现；不执行模型生成的代码。

## 可执行组件

### 纸感叠印 · paper-grain

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：纸纹以低透明度叠印在舞台上，保留图形轮廓。
- 价值：让数字图形具有温度与触感。
- 边界：复用本地纸纹；不生成新的笔刷。

### 手绘边饰 · ink-border

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：离散帧更新轻微不规则的线段与排线。
- 价值：加强手作气质，给画面建立边界。
- 边界：作用于舞台边缘，不替换角色骨骼。

### 聚焦光环 · focus-halo

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：以主体为中心的低对比光晕引导注意力。
- 价值：在复杂场景里突出正在行动的角色。
- 边界：跟随本镜第一名出镜角色。

### 行动轨迹 · line-trail

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：采样本镜真实位移，以逐段显现的虚线连接落点。
- 价值：让移动路径与方向更容易理解。
- 边界：只标记已有动作路径；不会创建新动作。

### 等轴参考网格 · iso-grid

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：使用两组平行斜线提示地面空间关系。
- 价值：帮助表达空间秩序和路径。
- 边界：二维网格，不增加三维几何。

### 柔光聚焦 · soft-spotlight

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：柔和径向光场与周边暗部突出主体。
- 价值：为重要时刻增加舞台感与视觉层次。
- 边界：二维光场；没有真实反射、阴影求解。

### 纸片场记 · collage-note

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：轻微转动的纸片承载本镜情绪标签。
- 价值：为回忆、日记和说明增加手工编排感。
- 边界：程序纸片与文字，不包含照片素材。

### 落点涟漪 · ripple

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：角色脚下的椭圆轮廓随时间扩散。
- 价值：用柔和的回响强调停留与动作落点。
- 边界：装饰性波纹，不是物理流体。

### 形状回响 · shape-echo

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：主体周围的多边形在连续轮廓间插值并扩散。
- 价值：用形状变化强调转折与情绪。
- 边界：独立装饰轮廓；不改变角色拓扑。

### 几何节拍 · geometric-beat

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：几何模块按固定帧间隔交替旋转、缩放。
- 价值：建立有秩序的视觉节奏。
- 边界：固定视觉节拍，尚未分析音乐 BPM。

### 霓虹扫描 · neon-scan

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：辉光扫描线和边缘短线按帧推进。
- 价值：传达电子、速度与复古氛围。
- 边界：二维发光，不添加真实三维环境。

### 极光光幕 · aurora-veil

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：透明渐变光场缓慢漂移并叠加。
- 价值：为平静或想象中的场景增加通透层次。
- 边界：没有玻璃折射或背景模糊采样。

### 情绪花字 · emotion-tag

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：读取本镜真实情绪，使用弹性缩放与多层描边。
- 价值：在情绪转折处加强可读性和幽默感。
- 边界：使用五种已有情绪；没有语音识别。

### 步骤标记 · step-badge

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：从时间轴读取当前镜头编号与总数。
- 价值：让过程、操作和知识讲解更有条理。
- 边界：展示镜头步骤，不进行事实核查。

### 像素火花 · pixel-sparks

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：整数格点上的方形粒子形成离散运动。
- 价值：用游戏语言强调变化与获得感。
- 边界：程序粒子，没有角色精灵动画资产。

### 主体追踪框 · tracking-frame

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：用投影后的主体坐标驱动角框与动作标签。
- 价值：让行动和状态成为可观察的信息。
- 边界：追踪故事中的角色，不接入外部传感器。

### 镜头缓推 · camera-push

- 状态：已接入；Canvas 2D · 按帧确定性绘制
- 原理：按本镜进度缩放舞台，以行动主体为构图参考。
- 价值：用景别变化引导观看和强调关键时刻。
- 边界：最多约 10% 的二维推进；标题字幕保持稳定。

## 十五种风格储备

### 扁平矢量

- 成熟度：基础画法原型
- 设计原理：有限色板、大色块与留白；动作通过挤压、拉伸和错峰入场形成节奏。
- 表达价值：把概念、关系和行动概括成一眼可读的图形，适合简短解释与轻快故事。
- 使用场景：产品解释 · 品牌短片 · 教育内容
- 视觉语言：有限高对比色板、简洁几何与留白；圆润轮廓与清晰字号；弹性起落、错峰入场，主体始终明确
- 可复用组件：聚焦光环、镜头缓推、形状回响
- 当前实现：Canvas 几何轮廓、弹性姿态与色块舞台；几何角色原型；未复刻上游 One Dot 分镜。
- 表达时避免：复杂写实细节与同时抢占注意力的大量元素。
- 待扩展：数据图表、品牌标识与图标路径组件；根据叙事节点生成色块转场与版式
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/01-flat-vector)，MIT。

### 线条动画

- 成熟度：基础画法原型
- 设计原理：连续线条连接叙事节点，用负空间和描绘顺序引导视线。
- 表达价值：表达连接、发现、流程和连续思考，让一条路径承担叙事。
- 使用场景：流程介绍 · 建筑概念 · 极简品牌
- 视觉语言：克制色板、细线与大面积负空间；轮廓生长形成观看顺序；沿路径推进，在转折处停留
- 可复用组件：行动轨迹、聚焦光环、镜头缓推
- 当前实现：Canvas 轮廓、路径逐段显现与跟随光点；程序轮廓描绘；尚未支持任意图标的一笔连接。
- 表达时避免：过细线条、小尺寸密集标注与没有因果的随机描线。
- 待扩展：可采样 SVG 路径库与连续图标连接；按路径事件生成镜头和声音节拍
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/02-line-art)，MIT。

### 等轴 2.5D

- 成熟度：基础画法原型
- 设计原理：保持平行的投影轴，用顶面、侧面、遮挡和投影组织空间。
- 表达价值：把系统、城市、协作关系变成可以观察的空间组织。
- 使用场景：架构说明 · 城市概念 · 物流流程
- 视觉语言：统一平行投影与层次配色；顶面、侧面和遮挡提示空间；按结构层级生长、装配与连线
- 可复用组件：等轴参考网格、行动轨迹、步骤标记
- 当前实现：Canvas 等轴投影、挤出方块与立体路径；2.5D 投影原型；没有上游 Three.js 的真实光照与遮蔽。
- 表达时避免：过多建筑遮挡，以及把投影网格误作真实三维。
- 待扩展：可参数化的 Three.js 建筑、节点与道路组件；数据驱动的装配顺序、遮挡控制与相机
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/03-isometric)，MIT。

### 3D 质感

- 成熟度：基础画法原型
- 设计原理：高光、明暗面、接触阴影和变形，共同提示物体的体积与重量。
- 表达价值：突出产品、字标或角色的材料与重量，形成视觉记忆。
- 使用场景：材质概念 · 品牌主视觉 · 发布会片头
- 视觉语言：材质色与柔和棚拍光；体积、接触阴影、反射共同建立触感；重量感、迟滞、形变与回弹
- 可复用组件：柔光聚焦、镜头缓推、聚焦光环
- 当前实现：Canvas 径向光照渐变、软阴影与棚拍舞台；二维体积近似，不是 Blender / Cycles 三维渲染。
- 表达时避免：把二维渐变当作已完成真实三维材质。
- 待扩展：Blender / Three.js 模型、材质与灯光资源包；预渲染序列帧接入时间轴及多语言包装
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/04-3d-render)，MIT。

### 逐帧手绘

- 成熟度：基础画法原型
- 设计原理：种子噪声改变墨线，一拍二和快速拉伸帧形成手工绘制的节奏。
- 表达价值：让角色具有手作温度；可向治愈、幽默或紧张等不同叙事气质扩展。
- 使用场景：情绪故事 · 儿童教育 · 文创短片
- 视觉语言：暖色纸张、墨色与少量强调色；不规则轮廓、错位填色和叠印；一拍二、姿态停顿和夸张反应
- 可复用组件：纸感叠印、手绘边饰、情绪花字、镜头缓推
- 当前实现：上游 MIT 绘线引擎、纸纹与本项目角色动作；沿用已实现的手绘舞台与笔刷；单角色、有限动作。
- 表达时避免：为抖而抖、轮廓闪烁，以及用字幕代替具体表演。
- 待扩展：不同情绪的笔刷、姿态库与关键表演组件；角色轮廓编辑、精细拿放与分镜构图规则
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/05-cel-boil)，MIT。

### 拼贴剪贴

- 成熟度：基础画法原型
- 设计原理：纸片、印刷纹理与尺度反差并置，用离散摆动模拟逐格摆拍。
- 表达价值：组织日记、记忆、文化与荒诞联想，用素材的并置制造含义。
- 使用场景：文化栏目 · 音乐视觉 · 历史故事
- 视觉语言：纸张、印刷色与不同尺度的拼接；剪切边缘、叠层与手工摆放；定格顿挫、错位与画面重组
- 可复用组件：纸片场记、纸感叠印、镜头缓推
- 当前实现：程序撕纸边缘、纸纹、分层剪影与定格摆动；使用程序纸片，没有照片拼贴、抠图或素材上传。
- 表达时避免：无关素材堆叠与未经授权的照片。
- 待扩展：授权照片、抠图与可编辑拼贴资产库；镜头穿梭大画布及纸片翻揭转场
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/06-collage)，MIT。

### 液态流动

- 成熟度：基础画法原型
- 设计原理：平滑距离场融合主体和跟随液滴，以细颈、拖尾和错时运动表达黏连。
- 表达价值：表达柔软、连接、变化与能量传递。
- 使用场景：饮料美妆 · 品牌融合 · 流体转场
- 视觉语言：有限相近色与柔和高光；圆润连续边界、融合与分离；缓慢蓄势、拉伸、流动与回弹
- 可复用组件：落点涟漪、极光光幕、形状回响
- 当前实现：CPU 采样平滑 SDF、低分辨率场放大与液滴拖尾；轻量液滴场；没有上游 WebGL 字标融合与液体物理。
- 表达时避免：在需要精确边界和快速读字时持续流动。
- 待扩展：WebGL 距离场融合与可控制的字标轮廓；适配动作事件的流动、分裂和拖尾
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/07-liquid)，MIT。

### 形变动画

- 成熟度：基础画法原型
- 设计原理：轮廓以相同数量的点建立对应，连续插值让一个形状变成另一个形状。
- 表达价值：表现对象之间的关联、身份转变与概念转换。
- 使用场景：图标动画 · 功能关联 · 品牌升级
- 视觉语言：简洁轮廓、少量强调色；对应轮廓点形成连续变化；预备、变形、辨认停留与下一次变化
- 可复用组件：形状回响、聚焦光环、镜头缓推
- 当前实现：80 点径向轮廓插值、旋转和轮廓残影；仅支持预设的简单单轮廓；不支持任意带孔图形。
- 表达时避免：只做装饰变形，或在变化后没有可辨认的停留。
- 待扩展：图标轮廓采样、对应点与拓扑处理；由故事关联驱动的对象变形语法
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/08-morph)，MIT。

### 几何包豪斯

- 成熟度：基础画法原型
- 设计原理：有限原色、严格网格与几何模块，通过重复、翻转和相位建立秩序。
- 表达价值：用秩序、重复和变化表达音乐性、系统性与设计感。
- 使用场景：设计展 · 动态海报 · 音乐节包装
- 视觉语言：原色、黑白与严格比例；网格、圆、半圆与几何重复；旋转、翻转和相位构成节奏
- 可复用组件：几何节拍、步骤标记、镜头缓推
- 当前实现：网格模块、半圆构成与帧号驱动的节奏变化；几何构成原型；配乐尚未分析 BPM 或自动卡点。
- 表达时避免：让装饰网格遮住故事信息。
- 待扩展：可编辑节拍表和参数化版式组合；音频节拍分析与系列动态海报
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/09-bauhaus)，MIT。

### 复古霓虹

- 成熟度：基础画法原型
- 设计原理：透视网格、条纹落日、霓虹辉光和扫描线共同建立复古电子氛围。
- 表达价值：表达复古电子、夜间旅程与速度感。
- 使用场景：电子音乐 · 游戏活动 · 复古品牌
- 视觉语言：深紫背景、荧光色与落日渐变；透视网格、发光轮廓和扫描线；持续前进、巡航与节拍闪光
- 可复用组件：霓虹扫描、像素火花、镜头缓推
- 当前实现：Canvas 透视网格、发光线条与扫描线；二维霓虹舞台；没有 Three.js 场景或完整 VHS 后期。
- 表达时避免：过强辉光、频闪和低对比文字。
- 待扩展：音乐联动的光效与可控 VHS 后期；三维道路、相机巡航和夜间空间
- 研究来源：[上游源码](https://github.com/Vincentwei1021/mg-styles-15/tree/49052d80bfaf9fa8412cc9710530e5e95a3b8d8c/demos/10-synthwave)，MIT。

### 极光玻璃

- 成熟度：基础画法原型
- 设计原理：柔和光场缓慢漂移，透明层、边缘高光与投影形成通透层次。
- 表达价值：适合安静、思考、想象与软件信息的通透包装。
- 使用场景：AI 工具 · 软件发布 · 功能亮点
- 视觉语言：低对比渐变与少量高光；透明叠层、边缘和柔和阴影；缓慢漂移、轻柔进入和层间视差
- 可复用组件：极光光幕、柔光聚焦、镜头缓推
