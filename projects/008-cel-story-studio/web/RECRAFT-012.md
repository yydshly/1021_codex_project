## 液态材质的实现与复现

`app/scripts/liquid-scene.py` 用 Blender Metaball 的连续等值面表达融合，再由 Cycles 计算玻璃透射、体积吸色、灯箱反射、环境和地面。它是按时间编排的表面变化，不是 Navier–Stokes 或软体模拟。初次试片裁切了成环轮廓，并出现过曝灯箱；先调整镜头与几何尺度，再限制灯箱在透射射线中的可见性，最后渲染 300 帧。试片保存在 `.cache/liquid-design-012*`，不作为交付成片。

默认组合由 `app/public/effects/studio-liquid-plate.mp4` 缓存；文字、时长和配乐继续由 Remotion 合成。改变配色、密度、细节、幅度或种子时服务重跑 Cycles。入口为 `scripts/material-cache.mjs`、`scripts/studio-render.mjs` 和 `POST /api/effects/render`。默认构图与渲染配置记录在 `assets/review-012/liquid-render-metadata.json`。

```powershell
cd projects/008-cel-story-studio/app
npm run render:liquid
node scripts/render-effects.mjs --style=liquid --videos --variants --timeline
```

需要 Blender 4.5+，可设置 `BLENDER_PATH`；默认优先使用已安装的项目缓存版本。默认静态成片无需启动 Blender，修改参数后的光线追踪导出耗时更长。
