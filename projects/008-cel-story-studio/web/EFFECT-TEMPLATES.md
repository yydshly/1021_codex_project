# 十五种独立效果模板

当前0.17重做手绘、形变与玻璃，各两套故事。0.16线条与科普的两套故事继续保留。工作台选择故事方案后可继续编辑并导出；配置使用可选storyId。有限资产，不是任意故事自动生成。详见PERFORMANCE-017.md与production-notes-017.html；十五项缺口依据见QUALITY-016.md。

第十五版进一步重做液态与HUD，详见MATERIALS-015.md；其他十三支保持0.14。第十四版制作记录：手绘《借一点风》、形变《把晴天放飞》、包豪斯《纸上游乐场》、线条《把海写成星空》、液态《流动的桥》重新组织原画和事件；拼贴、花字、科普补材料关系与完整剪辑；3D/2.5D/霓虹/像素/HUD逐项补前段识别、机位、接片、表演与状态。十五项保留本轮修改前的0.13工作台快照。作品成立与否以实际影片和审片为依据，不用测试数量或评分代替。进入production-notes-014.html看原作/修改前/本轮三版对照与方法总结。3D默认使用Cycles材质成片，修改材质重新离线渲染；液态014改为实时三维SDF曲面，不再调用旧三球圆环的Cycles缓存。

## 统一复用接口

`{kind:"effect-template", version:1, style, title, subtitle, words, primary, secondary, count, intensity, detail, seed, duration, sound?, shots?}`。文字、颜色、节点与种子是数据，不能执行代码或指定外部路径。`count` 3–14，`intensity/detail` 0–1，`seed` 1–9999，`duration` 4–20 秒，输出 1280×720 / 30 FPS MP4。新配置默认带原创合成配乐，可关闭；旧配置没有 sound 时保持无声。每个模板用自己的参数含义解释三个数值。支持保存、导入、浏览器草稿、保留内容跨模板切换，以及取用当前故事的标题与字幕节点；霓虹、像素、HUD新增 `shots:[{id,action,seconds,caption,framing}]`，全片4–20秒、每镜0.5–8秒、总和须匹配duration。`POST /api/effects/plan`使用现有本机AI，仅在当前资产的动作词表内编排，方案审阅后应用；尚无任意模型生成。其他十二模板仍未连接完整故事动作。

## 扩展方法

1. 在 `app/scripts/effects.mjs` 添加视觉机制、参数契约、默认内容、来源与边界。
2. 可复用渲染入口为 `app/src/effects/EffectScene.tsx`；本轮Canvas分发在 `canvas-v3.ts`，各风格独立影片在 `*-film-014.ts`，等点数轮廓与循环匹配在 `geometry.ts`，机械微缩世界在 `isometric-film.ts`，霓虹与HUD在 `neon-film-014.ts` / `hud-film-014.ts`，像素新片在 `pixel-film-014.ts`；镜头契约在 `film-program.mjs`，其余三维场景在 `three-v3.ts`，液体SDF在 `liquid-film-014.ts`、完整场景折射在 `prism-film-014.ts`。
3. 在结构化参数边界内加入品牌图形、素材组、产品数据或字幕时间轴，再增加对应控件；外部资产导入需要独立的尺寸、授权和路径约束，目前没有开放。
4. 复用原理继续添加组件时，同时实现参数、预览与导出；本轮 Blender 入口为 magnetic-scene-014.py / studio-render.mjs（liquid-scene.py仅保留历史工艺）（旧 studio-scene.py 保留），任务有材质渲染与合成阶段；后续加入流体物理时，也应新增引擎和任务状态，不得把二维近似标成原生三维。
5. 运行 `npm run typecheck`、`npm test`、`npm run build`，再用 `npm run render:effects` 生成十五份默认片和内容/参数/运动对照帧。

## 技术边界

这里是十五个可复用的效果模板，覆盖对应设计机制，不是源作全部影片代码和全部工艺的等价移植。已接入原创三维场景的 Cycles 渲染；软体解算、完整字形建模、任意故事的自动风格化、自由资产上传与语音字幕仍需后续扩展。完整来源与素材声明见 `app/public/effects/CREDITS.md`。
