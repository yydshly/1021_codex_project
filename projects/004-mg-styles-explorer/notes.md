# 研究与验证记录

研究日期：2026-10-20。固定上游版本：`49052d80bfaf9fa8412cc9710530e5e95a3b8d8c`。

## 研究方法

1. 阅读上游 README、15 份提示词、作品目录和主要渲染脚本，建立逐风格证据索引。
2. 将“可从源码确认的实现”“从画面提炼的设计原则”“未来扩展建议”分开表达。
3. 下载对应提交的 15 支影片、15 张封面、15 份提示词和许可证。
4. 保留原片于忽略的缓存目录；网页采用保持比例的 H.264 / AAC 压缩副本，使用本地文件以避免访问外部视频失败。
5. 为网页设计独立的 SVG 教学实验；这些示意不冒充上游成片或其实现。

## 容易混淆的技术点

- 提示词描述目标和约束，AI 可以据此编写代码；最终的画面由实际渲染程序计算，并非所有影片都调用生成式视频模型。
- 线条艺术与形态变换使用 SVG 路径采样，但最终画面由 Canvas 2D 绘制，不能把整个实现笼统称为 SVG 动画。
- 等距案例使用 Three.js 和正交投影；三维渲染案例涉及 Blender Cycles 离线帧与后续文字合成。
- 包豪斯案例不仅是几何排布，还使用 WebGL 印刷后处理。
- 像素案例以低分辨率画面为基础，配合调色板和 WebGL2 CRT 处理；单纯添加 `image-rendering: pixelated` 不等于复现全部效果。
- Remotion 可以承担 React 组件、帧时间轴和视频输出，但迁移不同渲染工程需要适配，并非安装后自动兼容全部案例。

逐项解释和实际证据路径保存在 `app/styles.json`。网页中的原作、提示词、实现代码链接均固定到研究版本。

## 验证方法与范围

自动验证结果见 `assets/verification.json`：

- 检查 15 项风格记录完整性、唯一性以及源码证据路径。
- 对 46 个来源文件（15 影片、15 封面、15 提示词、1 许可证）计算 Git blob SHA-1，与固定提交的 Git tree 比对。
- 对每个网页视频检查时长、视频与音频编码，并用 FFmpeg 完整解码，避免只检查文件存在。
- 将素材来源与原片 SHA-256 记录到 `assets/media-manifest.json`；可独立比对的来源索引位于 `app/source-index.json`。

浏览器验证：

- 桌面布局与 390 px 手机布局，无横向溢出。
- 搜索、空结果、分类筛选、打开和关闭详情、详情分页和标签切换。
- 本地视频实际播放、提示词复制成功反馈。
- 原理实验的播放、暂停、进度拖动和模式切换。
- 制作链路与场景标签切换，风格推荐打开对应详情。
- 截图保存在 `assets/cover.jpg`、`assets/mobile.jpg`、`assets/detail-mobile.jpg`。

最终结果：15 项风格、15 份提示词、15 支本地影片均已构建；46 个原始文件哈希一致，15 支影片完整解码通过。网页视频合计约 41.4 MB，整个 `web/` 约 45.4 MB。浏览器逐一检查了 15 项详情与媒体映射，实际播放了横版和竖版影片，竖版保持原比例。额外截图位于 `assets/gallery.jpg`、`assets/detail-desktop.jpg`。

浏览器检查通过本地 HTTP 服务完成；没有通过自动化验证 `file://` 入口。静态输出已内嵌内容数据，未依赖 API 或运行时数据请求。

仓库要求的 6 项单元测试通过，`python scripts/catalog.py --check` 通过，`git diff --check` 未发现空白错误。

## 本地播放修复

用户反馈无法播放后，检查发现 8044 端口没有服务监听。此前预览服务被关闭，浏览器仍保留旧页面，后续视频请求失败。恢复本地后台服务并刷新页面后，原先失败的形变影片已成功加载并播放。

新增 `app/serve.py`，以本机 HTTP 服务提供视频分段请求（206）与进度跳转支持；浏览期间保持该进程运行。检查了全部 15 支影片的分段响应与真实文件字节，另验证后缀请求、中段请求、开放结束位置、无效范围（416）和 HEAD 响应。结果见 `assets/playback-check.json`。
